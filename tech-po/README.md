# Technical PO 이력서

- 원본: `tech-po/resume.md`. 메인 `resume.md`와 독립적으로 편집한다.
- 웹 경로: `/tech-po/`, PDF 경로: `/tech-po/resume.pdf`.
- 저장소 루트에서 `quarto render`를 실행하면 메인과 이 버전의 웹·PDF를 함께 생성한다.
- 디자인과 PDF 출력 방식은 메인과 공유한다. 메인 이력서는 변경하지 않는다.
- 상단 직무명은 지원용 포지셔닝이다. 경력 제목의 Problem Solver는 수행 역할을 설명하는 표현이며, 공식 인사 직무명은 Full-Stack Engineer (App, Web, AI)다. 확인된 성과·책임 범위는 유지한다.
- 두 원본의 공통 사실을 정정할 때는 양쪽을 확인한다. 다른 버전의 문구를 자동으로 덮어쓰지 않는다.
